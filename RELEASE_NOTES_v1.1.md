# PHYSIOGRAPH v1.1 | Experimental Deep Learning + Live Neural Monitor

**Challenge:** Create Health Monitoring Software for Astronauts on Space Missions (NASA Space Apps Challenge 2026).

## Implemented

- Genuine 1D convolutional autoencoder using PyTorch. Its 5 inputs are heart rate (bpm), SpO2 (%), respiratory rate (breaths/min), core temperature (°C), and RMSSD HRV (ms).
- Reproducible normal-only synthetic model training, held-out subject/profile-based calibration and testing, pretrained versioned weights (`models/deep_learning/cnn_autoencoder.pt`), and JSON evaluation artifact.
- Fixed per-subject initial 45-second reference, followed by 60-second model evaluation windows at **exactly 1 Hz**. Missing measurement and irregular-cadence packets produce explicit no-inference statuses.
- Server model endpoints (`/api/live/dl/model`, `/api/live/dl/{subject_id}`, `/api/live/dl/history/{subject_id}`); model novelty status appears alongside streaming telemetry. The model service gracefully degrades if PyTorch or model weights are unavailable.
- A standalone local web viewer at `http://127.0.0.1:8000/live`, showing five simulated signals, a selected signal trend, reconstruction errors, model flags and source labels.
- Two fictional replay modes: `--mode normal` and `--mode excursion`. Neither contains real NASA sensor values or clinical outcomes.

## Results of synthetic held-out test

See `models/deep_learning/synthetic_evaluation.json`. The scripted generator produces separate PRNG streams and profiles for the 2,400 normal training episodes, 480 normal calibration episodes, and 480 normal test episodes. It also produces 160 positive examples for each of seven artificially perturbed scenario types. These are **numerical software demonstrations, not clinically meaningful sensitivity/specificity estimates**.

The model uses a reconstruction-error threshold set to the **95th percentile** of normal validation scores. Observed held-out synthetic normal false-flag rate: **2.92%** (14 / 480). For the large injected perturbation scenarios, model flags were 100% within this synthetic generator. A subtle drift was flagged in **48.75%** (78 / 160) and a low-magnitude transient in **83.75%** (134 / 160). Overall synthetic labeled AUC **0.981**. These results are generator-dependent and **are not evidence of astronaut health prediction or generalization**. Thresholds and architecture are exploratory, not clinically or mission qualified.

A separate simple sinusoidal normal replay was checked during model development. The original narrower synthetic generator caused excessive false flags there; broader benign normal cycles were then included in training. This replay check is consequently **development feedback rather than independent external validation**. Report the tradeoff: a broader normal distribution reduced false flags but made subtle deviations harder to detect.

## Safety, provenance and limitations

- The 1D-CNN has never seen NASA OSD-575 measurements. It does not infer diagnoses, triage levels, clinical probabilities, or treatment.
- Historical NASA postflight biomarker data continue to be analyzed by unchanged APDRA. No synthetic or neural model result is passed into frozen APDRA, and no APDRA finding is represented as CNN training data.
- No oxygen or blood-pressure emergency thresholds are asserted. Values have only broad technical input-validation limits.
- The simulated training subjects and held-out test subjects are generated by **the same simulator family**. High scores on its self-generated disturbances do not imply external robustness; false flags may rise on real physiological signals or different sampling devices.
- A model flag may remain present after a disturbance ends because the 60-second rolling window still contains earlier unusual points.
- 1 Hz regular sampling, complete 5-channel packets and initially representative reference period are required. No missing-value interpolation, automatic baseline mutation or ECG waveform prediction.
- Local-only API is not authenticated and must not be exposed to public networks or used with personal health data.

## Windows: quick demonstration

1. Extract this ZIP into a new folder. Use Python 3.11 or 3.12 if possible.
2. Double-click `INSTALL_DEEP_LEARNING_WINDOWS.bat` once. PyTorch can require a substantial download.
3. Start `START_LIVE_BACKEND_WINDOWS.bat`. Open `http://127.0.0.1:8000/live` in a browser.
4. Start `RUN_LIVE_NORMAL_WINDOWS.bat` to see the fictional normal replay. Then optionally start `RUN_LIVE_REPLAY_WINDOWS.bat` to see the fictional multi-signal excursion. These have separate subject IDs.
5. Use `RUN_BACKEND_TESTS_WINDOWS.bat` to run all software tests. Optionally retrain model with `RETRAIN_CNN_WINDOWS.bat`.

For a command-line setup:

```sh
python -m pip install -r requirements-deep-learning.txt
python -m uvicorn physiograph.live_api:app --host 127.0.0.1 --port 8000
# In a separate terminal:
python -m tools.replay_live_demo --speed 10 --mode excursion
```

**The new live viewer is not the final HELIOS-style UI**, and does not replace the four research sections in the Streamlit application. It is a functional model-driven monitoring demonstration and an integration base for the final frontend.
